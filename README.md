# 一箭又一箭（Arrow Escape）

一个使用 Python 和 Pygame 编写的方格箭头消除小游戏。

玩家通过鼠标点击棋盘中的箭头：如果箭头朝向直到棋盘边界之间没有其他箭头，它就会飞出棋盘并消失；如果前方存在阻挡，则箭头不能消失，同时扣除一次失误机会。清空全部箭头即可通关，失误次数耗尽则挑战失败。

## 功能特点

- 图形化的开始、关卡选择、游戏和结算界面；
- 上、下、左、右四种箭头；
- 四个方向的路径检测与棋盘边界处理；
- 飞出动画和碰撞反馈动画；
- 剩余箭头数、失误次数、得分和计时显示；
- 至少 3 个可以正常通关的固定关卡；
- 通关、失败、下一关和重新开始功能；
- 自动保存和恢复游戏进度。

在基础功能之外，项目还实现了以下扩展：

1. 多关卡与关卡选择；
2. 得分、计时和星级评价；
3. 提示功能；
4. 撤销上一步；
5. 保存游戏进度；
6. 随机生成可通关关卡；
7. 自动求解当前关卡。

## 开发环境

- Windows 10/11；
- Python 3.12；
- Pygame 2.6.1；
- Visual Studio（安装“Python 开发”工作负载）。

## 安装和运行

### 1. 安装 Python

安装 Python 3.12 64 位版本，并在安装时勾选 `Add python.exe to PATH`。

### 2. 安装 Pygame

在命令提示符中执行：

```bash
py -3.12 -m pip install pygame
```

可使用下面的命令检查安装结果：

```bash
py -3.12 -c "import pygame; print(pygame.version.ver)"
```

### 3. 运行游戏

进入项目目录后执行：

```bash
py -3.12 ArrowEscapeGame.py
```

也可以在 Visual Studio 中打开项目，将 `ArrowEscapeGame.py` 设置为启动文件，然后按 `Ctrl + F5` 运行。

## 游戏操作

| 操作 | 方法 |
|---|---|
| 选择箭头 | 鼠标左键点击箭头所在方格 |
| 重新开始 | 点击“重开”或按 `R` |
| 获取提示 | 点击“提示”或按 `H` |
| 撤销一步 | 点击“撤销”或按 `U` |
| 自动求解 | 点击“自动求解”或按空格键 |
| 返回首页 | 点击“保存并返回”或按 `Esc` |

## 游戏规则

设被点击箭头位于第 `row` 行、第 `col` 列，方向增量分别为：

```python
DIRECTIONS = {
    "U": (-1, 0),
    "D": (1, 0),
    "L": (0, -1),
    "R": (0, 1),
}
```

程序从相邻方格开始，沿箭头方向逐格检查：

- 如果检查过程中遇到其他箭头，说明前方有阻挡；
- 如果一直到越过棋盘边界都没有遇到箭头，说明路径畅通；
- 路径畅通时播放飞出动画，并把该格设置为空；
- 路径受阻时保留箭头，扣除一次失误机会并播放碰撞反馈。

程序内部主要分为：

- 棋盘逻辑：路径检测、可用操作查询、关卡生成和求解；
- 游戏状态：开始、选关、游戏、通关和失败；
- 交互逻辑：点击、提示、撤销、重开和自动求解；
- 图形绘制：棋盘、箭头、按钮、动画和状态信息；
- 数据保存：游戏进度和关卡最佳评价。


| T06 | 游戏过程中重新开始 | 棋盘和失误次数恢复初始状态 |
